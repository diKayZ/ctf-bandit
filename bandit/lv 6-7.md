# TASK
find the password swhere in the server matches <br>
***owned by user bandit7 <br>
owned by bandit6 <br>
33 bytes in size***
# PROCESS
bcuz it says swhere in the server so instead of `ls -al` <br>
--> we should use `find` to optimize the time
```bash 
find / -user bandit7 -group bandit6 -size 33c 
```
but we can see that the outputs are just many ***PERMISSION DENIED*** <br>
--> so we can put all of them to *black hole* by using `2>/dev/null` except the path that has the pass 
```bash
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null
```
(`2>` which means select the errors exsited then moved to `dev null`)
then we have the path so just cat it and get the passwd
```bash
cat /var/lib/dpkg/info/bandit7.password
```
